Kraken scripts

Small browser add-ons that fill in the repetitive bits of Kraken. Install the ones you need — they update themselves after that.

First time here

  1. Add Tampermonkey Install the browser extension and pin it to your toolbar.
  2. Install a script Click Install below. Tampermonkey opens a tab — confirm there.
  3. Reload Kraken The new buttons appear on the pages each script covers.
