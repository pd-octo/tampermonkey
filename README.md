# Octopus Connections – Tampermonkey Scripts

![GitHub last commit](https://img.shields.io/github/last-commit/pd-octo/tampermoney)
![Scripts](https://img.shields.io/badge/scripts-6-blue)


A collection of Tampermonkey userscripts to make common Connections tasks in Kraken faster and reduce repetitive manual work.

## Getting Started

### 1. Install Tampermonkey

If you don't already have Tampermonkey installed, follow the setup guide included in this repository. How to set up Tampermonkey scripts.pdf

### 2. Install a script

Click the script you want below, then click **Raw**.

Tampermonkey will automatically open an installation prompt.

Once installed, scripts will update automatically whenever a new version is released.

## Updating

Scripts update automatically through Tampermonkey.

If an update is available, Tampermonkey will install the latest version automatically (or prompt you, depending on your settings).

There is nothing you need to do after the initial installation.
